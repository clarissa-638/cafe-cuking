PURRFECT DAY - PEMISAHAN ROLE

Struktur:
- main.py     : halaman login dan penghubung semua role
- admin.py    : halaman Admin
- kasir.py    : halaman Kasir
- waiter.py   : halaman Waiter
- pembeli.py  : halaman Pembeli dan pemesanan menu

Cara menjalankan:
1. Simpan semua file .py dalam satu folder.
2. Letakkan background.jpg dan logopurr.png di folder yang sama.
3. Letakkan gambar menu (croissant.jpg, es_teh.jpg, mie_ayam.jpg,
   kopi_susu.jpg) di folder yang sama, atau sesuaikan path gambarnya.
4. Pastikan Python, Pillow, dan Tkinter tersedia.
5. Buka terminal di folder proyek, lalu jalankan:
   python main.py

Akun login:
- Admin   : username admin, password admin
- Kasir   : username kasir, password kasir
- Waiter  : username waiter, password waiter
- Pembeli : username pembeli, password pembeli

Catatan:
File pembeli.py mempertahankan fitur menu, pencarian, kategori,
keranjang, total harga, dan konfirmasi pesanan dari kode awal.
